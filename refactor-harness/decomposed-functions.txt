# Functions the refactoring has deliberately restructured, by stage.
#
# Why this file exists
# --------------------
# The supplementary L0 check compares every function of the baseline SisProd.cpp
# against wherever it lives now, token for token. A stage that decomposes a
# function, adds a parameter or requalifies a call changes the token stream on
# purpose, and the check reports it. That is correct, and it is also noise that
# accumulates: by the tenth stage the report would carry a hundred permanent
# differences, and a function that vanished for a bad reason would be
# indistinguishable from one that moved as planned.
#
# Naming a function here says: this stage changed its token stream on purpose,
# and verified it some other way. Everything NOT named here must still be
# token-for-token identical. A name here that turns out to compare equal is
# reported as a stale declaration, so the list cannot rot.
#
# This is not a way to silence a failure. It is a way to keep the remaining
# failures worth reading.
